2026-10-13 (Tuesday): Casbaneiro Banking Trojan Paired With Malicious Chromium Extension and Delivered via Abused Remote Access Tooling

AUTHORS:

- Anikait Panigrahi, Abhiram Patiballa, Saide Sheikh, Guy Weiner

NOTES:

- We observed the Casbaneiro banking trojan family (also tracked as Metamorfo and Ponteiro) delivered alongside a malicious Chromium extension, with infrastructure for both still live at the time of writing.
- Initial access came from a phishing email that led the user to install a client for an abused trial tenant of a legitimate remote-access product, which the operators then used to run PowerShell directly on the host.
- The chain deploys two parallel components: a Delphi payload side-loaded through a legitimately signed installer utility, and a malicious Chromium extension side-loaded into the victim's browser.
- The Chromium extension resolves its command-and-control server from a plain-text file hosted on an attacker domain, then maintains a WebSocket channel for screenshot capture, cookie theft, form-field capture including passwords, and operator-driven HTML overlay injection.
- The extension is controlled through an operator web panel that the operators themselves brand "Painel Gangster". We first saw the name in an operator panel data file submitted to a public malware repository in September 2025, then confirmed it on live panel hosts, including the WebSocket C2 contacted in this intrusion.
- The side-load abuses a signed Caphyon Advanced Installer component (VmLauncher.exe), which is made to load a malicious DLL named zlibai.dll that masquerades as the zlib compression library.
- The extension's operator panel data shows a target list of roughly 65 Portuguese and Brazilian banking portals, 11 cryptocurrency exchanges, several webmail providers and typosquatted webmail hostnames.

DETAILS:

- A phishing email directs the victim to install a client for a legitimate remote-monitoring and management product from an attacker-registered trial tenant of that vendor's cloud service. The client installs as a Windows service, giving persistent interactive access.
- From that session the operators launch PowerShell, which retrieves an archive containing an unpacked Chromium extension from a public file-sharing service, and separately retrieves a signed installer utility together with a malicious DLL from an attacker-controlled web server.
- The DLL is renamed to match the import expectations of the signed utility and placed alongside it. When the utility runs, Windows search-order resolution loads the malicious DLL instead of a legitimate library.
- The malicious DLL is Delphi-compiled and exports a set of decoy zlib-style functions that satisfy the host binary's import table while performing no real compression work. During process attach it patches the host executable's entry point in memory, redirecting execution into its own handler.
- That handler hides the host application window, then enters a loop that checks for network connectivity, decrypts a command string using a custom XOR routine driven by a 150-byte key table, and executes it. The string-encryption scheme is characteristic of this family.
- Separately, the browser is launched with a command line pointing at the extracted extension directory. The extension manifest is Manifest V3 and requests storage, tabs, webNavigation, scripting, activeTab and cookies, with content scripts matching all URLs in all frames. It declares no public key and no update URL, so it is side-load only and never passes through the Chrome Web Store.
- On startup the extension fetches a plain-text file from an operator domain. The response supplies the active WebSocket endpoint. The client generates a 10-character uppercase identifier and maintains the session with periodic pings.
- Server-to-client commands include screenshot capture, cookie retrieval, HTML payload injection and removal of injected HTML. Client-to-server messages include screenshot data, cookie data, tab listings, monitored-site-visited events and captured input data.
- A companion content script registers a listener on form fields across every page. When a field loses focus it captures the page URL, the field name, the field value and a timestamp, and relays them to the service worker for exfiltration. Password fields are captured unconditionally.
- Injected overlays are fetched per-URL from an operator endpoint and rendered using predictable DOM element identifiers, which gives defenders a reliable hunting artefact in browser telemetry.
- An earlier build of the extension also rewrote navigation targets using the Chrome webNavigation API for phishing redirection. That code was removed in later builds, though the permission remains declared in the manifest.
- Earlier builds contain Portuguese-language function names and user-facing error strings. Later builds were translated to English, the version numbering was reset, and internal filenames moved from numeric to semantic — changes consistent with a deliberate effort to frustrate clustering.
- The "Painel Gangster" operator panels run Node.js Express behind nginx and expose a consistent set of API paths for client management, overlay configuration, screenshot and cookie retrieval, and notification muting via a messaging-platform integration. Some panels are CDN-fronted; others are reachable directly.
- TLS certificates for the extension's resolver domain are wildcard-only and rotate on a roughly two-to-three-month cadence between two issuers, Google Trust Services (WE1) and Sectigo. The earliest was issued on 2025-05-26, the day the domain was registered, and the most recent on 2026-09-16. Related actor domains add Let's Encrypt as a third issuer. Rotating across multiple certificate authorities defeats hunting rules keyed to a single issuer.
- The extension platform and the Delphi payload use separate command-and-control infrastructure on different providers, consistent with deliberate compartmentalisation of delivery, panel and C2 functions.
