NOTES:

- We observed a trending campaign of the Remus Infostealer delivered through a shared "fake pirated software" SEO-poisoning network impersonating cracked productivity tools.
- The lure is a fake "İndir - Full" (Turkish for "download") archive served from a malicious site, distributed alongside a catalogue of fake pirated games and cracked apps. The recurring Turkish-language lures suggest this campaign may be targeting Turkish users.
- The malware injects into the user's running instances of popular Chromium-based web browsers via CREATE_REMOTE_THREAD to gain access to the browser vault.
- Stolen data is exfiltrated over HTTP to freshly registered C2 domains, using a spoofed Host header impersonating a major technology vendor's domain to disguise the upload as legitimate diagnostic or telemetry traffic.
- Remus implements distinct collection capabilities targeting leading gaming platforms, popular web browser credentials, clipboard, screenshots, FTP creds, and enterprise email client storage files, and resolves its C2 URL dynamically from an Ethereum smart contract.
- Several of the delivery domains are open directories actively hosting malware, with fresh samples uploaded as recently as 2026-07-27.
- While this campaign centers on the Remus Infostealer, we also identified samples of other infostealers staged in the same open directories, indicating shared distribution infrastructure across multiple malware families.


DETAILS:

Initial Access: SEO-Poisoned Malicious Site

- The lure archive impersonates a cracked popular PDF reader tool and is downloaded from a malicious site.
  - [Popular_PDF_Reader]_2023_İndir_-_Full_v2023....zip from hxxps[://]dwn[.]metaforgechain4[.]lol/g/zip/...
  - The folder name uses the Turkish word "İndir" ("download"), the classic pirated-software SEO bait.
- The domain is hosting a full warez storefront, not a single lure page. It serves a catalogue of fake cracked games and apps.
  - Sample catalogue entries include heavily pirated titles: [Leading_FPS_Game]_WWII_İndir_-_Full_PC_Türkçe___MP....zip, [Classic_RTS_Game]_2_İndir_-_Full_Türkçe___Online_-_MP_PC.zip, [Popular_Football_Game]_2021_İndir_-_Full_Türkçe....zip, [Football_Simulator]_16_Türkçe_Yama_İndir....zip, [Game_Simulator]_v1.3.55_Legacy.zip.
  - The cracked popular PDF reader tool archive is one tool on the same host.
- The campaign is Turkish-language targeted. Filenames repeatedly carry İndir / Türkçe / Yama, indicating a TR-focused victim pool.

Execution & Process Injection

- Once the victim extracts the downloaded archived zip, and runs the primary executable, the malware initiates process injection (CREATE_REMOTE_THREAD) directly against active web browser processes. This grants it in process access to target and harvest stored credentials and sensitive secrets held within the browser vaults.
- Directly following this injection activity, the payload manages its own outbound command-and-control (C2) communications by establishing connections to two newly registered external infrastructure hosts.

Remus Collection Capabilities

- The Remus Infostealer implements distinct collection capabilities targeting gaming platforms, browser credentials, and general system data. The tools and services listed below are part of what Remus targets, and not the full scope.
- Gaming platform theft:
  - Gaming platforms: harvests session cookies from the platform's local application data directories.
  - Game storefronts: reads installation credentials by querying the registry keys associated with the storefront's software vendor for the installation path values.
- Browser credential theft:
  - Chromium-based browsers: reads OS-level encrypted master keys from the local state files to decrypt saved passwords.
  - The stealer targets the default login data, web data, and history directories of the market's leading web browsers, retrieving the AES key necessary to unlock these secrets.
  - Retrieves the native OS data protection API master key from the operating system's default application data protection paths.
     - Grabbing this master key means the actor is not just stealing an encrypted blob, they can decrypt the saved secrets offline.
- Password manager theft: targets local data directories of several password management applications.
- Cryptocurrency focused browser extensions: targets local extension settings directories for specific wallet extension IDs indicating a focus on cryptocurrency-related extensions.
- FTP credential theft: targets stored credentials from a variety of popular FTP client applications.
- Clipboard theft: captures clipboard content via GetClipboardData.
- Screenshots: takes screenshots using BitBlt on a hidden desktop created with CreateDesktopW.
- Email storage enumeration and sandbox evasion:
  - Enumerates enterprise email client local storage files (like PSTs) in the user's Documents folder.
  - This also functions as a sandbox evasion check against commonly known honeypot filenames.
- System reconnaissance:
  - Collects username, computer name, and domain information via GetUserNameA and GetComputerNameA.
  - Determines privilege level through token integrity checks.

Command and Control: Ethereum Anchored Resolution and Shared HTTP C2

- Remus resolves its C2 URL dynamically by querying an Ethereum smart contract.
  - Contract address 0x999941b74F6bbc921D5174A5b29911562cd2D7CF.
  - Queried through hxxps[://]ethereum-rpc[.]publicnode[.]com.
- Stolen data is exfiltrated via HTTP POST to the resolved C2 URL.
  - POST body format: access_token=<C2_URL>&debug=<encoded_data>.
- Observed C2:
  - fimmora[.]surf -> 165.227.123[.]79:6504.
  - zelpx[.]garden -> 77.42.90[.]175:9895.
  - tzpx[.]courses -> 167.99.78[.]100:4437.
- The malware forges a Host header to impersonate legitimate traffic to a leading technology vendor, while the real destination is a C2 node hosted on a common cloud infrastructure provider.

Multi-Family Staging

- Although this campaign is focused on the Remus Infostealer, the open directories are not limited to a single malware family.
  - Alongside the Remus samples, we identified samples belonging to other infostealer families staged in the same open directories.
  - This indicates the delivery network is shared infrastructure used to distribute multiple, unrelated infostealers rather than a single-family operation, consistent with the "fake cracked software" distribution-as-a-service model.
- Shared, rotating C2.
  - 165.227.123[.]79 also hosts fasea[.]top, noevara[.]shop, dikdiy[.]xyz, fluokq[.]xyz, approe[.]shop, dolmaq[.]shop.
  - 77.42.90[.]175 also hosts dreaub[.]top and pivotq[.]top, and zelpx[.]garden historically used a third node, 143.244.141[.]187.
- One registration system.
  - The C2 and sibling domains are bulk-registered in tight July-2026 windows on different TLDs (.surf .garden .top .shop .xyz), all with hashed/privacy WHOIS and reused nameservers (dyna-ns.net, dnsowl.com).
  - Pronounceable 5-6 letter nonsense labels, registered days before use, short-lived.
