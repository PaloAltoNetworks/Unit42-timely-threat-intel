2026-07-21 (TUESDAY): FURTHER MALICIOUS INFRASTRUCTURE FROM NPM AND PYPI SUPPLY CHAIN PACKAGES

AUTHORS:

- Rui Zhao, Micah Yates

NOTES:

- We've identified further malicious packages across the npm and PyPI registries.
- As previously noted, like other publicly-available software repositories, criminals have abused npm, PyPI and other registries. References:
  -- https://unit42.paloaltonetworks.com/monitoring-npm-supply-chain-attacks/
  -- https://about.gitlab.com/blog/gitlab-discovers-widespread-npm-supply-chain-attack/
  -- https://www.microsoft.com/en-us/security/blog/2026/05/29/33-malicious-npm-packages-abuse-dependency-confusion-profile-developer-environments/
  -- https://unit42.paloaltonetworks.com/malicious-packages-in-pypi/
  -- https://www.fortinet.com/blog/threat-research/malicious-packages-hidden-in-pypi
  -- https://www.zscaler.com/blogs/security-research/malicious-pypi-packages-deliver-silentsync-rat
- Most of the packages we've found remain live on public registries at time of publication
- Attack types include:
  -- cloud credential exfiltration (Kubernetes service account tokens, SSH keys, AWS credentials, Ethereum keystores)
  -- EtherHiding blockchain-based C2 droppers that resolve infrastructure from Ethereum mainnet smart contracts
  -- Solana cryptocurrency wallet key theft via Telegram
  -- .env file secret exfiltration
  -- install-hook fetch-exec droppers with bundled mass-typosquat publishers
  -- fake-CAPTCHA social engineering remote code execution
  -- Discord token theft and GitHub Actions CI/CD credential exfiltration
  -- dependency-confusion install-time callbacks
- All packages are detected by Palo Alto Networks WildFire
- Cortex XDR and XSIAM provide behavioral detection for post-installation activity
- These packages represent multiple distinct threat actors rather than a single coordinated campaign.
- While some of these packages have been previously disclosed by other researchers, most are novel Unit 42 findings.
