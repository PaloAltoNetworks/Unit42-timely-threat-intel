DETAILS:

- Campaign 1 technical analysis: 
  -- Single-image preview wrapper lures
  -- Lure behavior and victim view:
     --- Victims open a drawing preview link 
         ---- Link displays an online retailer's account verification card 
         ---- The card has a yellow 'Continue Verification' button under a randomized document title
  -- DOM and preview image delivery mechanics:
     --- The 83,214-byte top-frame DOM contains:
         ---- 0 visible words
         ---- 0 input tags
         ---- 0 canvas tags
         ---- 1 empty 1.4 KB SVG wrapper
     --- The DOM does not have text or form elements inside the HTML markup
     --- Instead, the page fetches the entire verification card as a 1200x630 preview image
         ---- From a popular cloud services providr URL
         ---- The URL parameter is: =w1200-h630-p
     --- The DOM renders the image inside the preview container
         ---- This method does not expose any lure words in the DOM

- Campaign 2 technical analysis:
  -- Fake PDF.js viewer painting blurred bank transfer receipts on HTML5 canvas 
  -- DOM and script execution mechanics:
     --- The 18,666-byte HTML document
         ---- Sets meta robots="noindex, nofollow, noarchive" and referrer="no-referrer"
         ---- Loads custom PDF.js stylesheets (vendor/pdfjs/web/pdf_viewer.css and styles.css)
         ---- Dynamically injects ES modules download-dialog.mjs and app.mjs
              ----- Done via document.createElement('script') with script.type = 'module'
     --- Inside div#viewer-container > div.document-preview-frame > div#pdf-viewer.pdfViewer:
         ---- The kit renders a blurred interbank wire transfer receipt 
              ----- Rendered onto a 974x1260 HTML5 canvas element (1,227,240 square pixels, role="presentation") 
              ----- Paired with a second hidden canvas (canvas.hiddenCanvasElement) 
              ----- Overlaid with a trigger button (button.preview-eye[data-open-download])
     --- Clicking button.preview-eye or button#open-file:
         ---- Calls showModal() on native HTML5 dialog#password-dialog
              ----- Contains
                    ------ Form#password-form
                    ------ Input#pdf-password[type="password"][autocomplete="off"][required]
              ----- This is done to harvest credentials under the pretext of:
                    ------ Inlocking an encrypted PDF
                    ------ Opening dialog#app-download-dialog to deliver a mobile payload
                           ------- Contains a#download-app

- Campaign 3 technical analysis: 

  -- Vector SVG defs/use coordinate-grid QR-code session-hijacking lures (perehod[.]website):
  -- DOM and SVG coordinate-grid mechanics:
     --- The 322,322-byte DOM is a SvelteKit application (__sveltekit_3hl3a)
         ---- This imports:
              ----- /_app/immutable/entry/start.CP8bQY5P.js
              ----- /_app/immutable/entry/app.BHnh9mMq.js
         ---- It then registers /service-worker.js under a trustedTypes.createPolicy
              ----- This is a 'sveltekit-trusted-types', ... policy 
         ---- It registers the policy while impersonating the MAX Messenger web login
              ----- Sign in to MAX via QR code
     --- The DOM contains:
         ---- 0 img tags
         ---- 0 canvas tags
         ---- 0 input tags
         ---- only 27 visible words
         ---- 6 SVG elements totaling 315,960 bytes, including:
              ----- A 251,859-byte hidden icon sprite svg#max-icons-sprite 
              ----- A 62,532-byte QR code SVG file 
                    ------- With viewBox="0 0 4059 4059" and width="220px" height="220px").
     --- This DOM does not embed a standard QR image or painting a canvas
     --- Instead, the 62,532-byte QR SVG file defines 11 modular vector shapes inside defs:
         ---- rect#rect-0 of size 100x100
         ---- path#empty-0
         ---- path#b-0
         ---- path#r-0
         ---- path#l-0
         ---- path#t-0
         ---- path#lt-0
         ---- path#lb-0
         ---- path#rb-0
         ---- path#rt-0
         ---- finder pattern #point-0
     --- The SVG file also constructs the QR matrix
         ---- It does this through hundreds of g[transform="translate(X,Y)"] > use[xlink:href="#..."] coordinate instances
              ----- These instances are across the 4059x4059 grid
              ----- They overlay the hotlinked center logo via clip-path="url(#logo-mask-0)"
