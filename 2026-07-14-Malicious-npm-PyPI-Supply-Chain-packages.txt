2026-07-14 (TUESDAY): MALICIOUS INFRASTRUCTURE DERIVED FROM NPM AND PYPI SUPPLY CHAIN PACKAGES

AUTHORS:

- Rui Zhao, Micah Yates

NOTES:

- We've identified a number of malicious packages across the npm and PyPI registries.
- Like other publicly-available software repositories, criminals are known to abuse npm, PyPI and other registries. References include:
  -- https://unit42.paloaltonetworks.com/monitoring-npm-supply-chain-attacks/
  -- https://about.gitlab.com/blog/gitlab-discovers-widespread-npm-supply-chain-attack/
  -- https://www.microsoft.com/en-us/security/blog/2026/05/29/33-malicious-npm-packages-abuse-dependency-confusion-profile-developer-environments/
  -- https://unit42.paloaltonetworks.com/malicious-packages-in-pypi/
  -- https://www.fortinet.com/blog/threat-research/malicious-packages-hidden-in-pypl
  -- https://www.zscaler.com/blogs/security-research/malicious-pypi-packages-deliver-silentsync-rat
- Most of the packages we've found remain live on public registries at time of publication
- Attack types include: 
  -- .env credential exfiltration
  -- cryptocurrency wallet key theft
  -- cross-platform clipboard hijacking
  -- malicious MCP servers targeting AI/LLM developers
  -- remote code execution droppers
  -- a reverse shell with AnyDesk persistence
  -- and a Discord account destroyer
- All packages are detected by Palo Alto Networks WildFire
- Cortex XDR and XSIAM provide behavioral detection for post-installation activity
- These packages represent multiple distinct threat actors rather than a single coordinated campaign.
- While some of these packages have been previously disclosed by other researchers, most are novel Unit 42 findings.
