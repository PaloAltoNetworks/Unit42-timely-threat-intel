NOTES:

- Unit 42 has identified a framework called VoidShadow
  -- This is a modular, cross-platform post-exploitation implant framework
  -- We have so far discovered Linux and Windows samples
- The framework provides:
  -- Full remote control of a compromised host
  -- Credential theft
  -- Layered stealth and persistence, including userland and kernel-mode rootkits
- VoidShadow agents run C2 communications over TLS, disguising beacons as trusted cloud and web traffic, such as
  -— Microsoft Graph (e.g., /microsoft.graph.v1.Policy/Sync)
  -- WordPress (e.g., wp-login.php, wp-admin/admin-ajax.php)
  -- Google Cloud (e.g., /v1/projects/{project_id}/logs:write, /v1/projects/{project_id}/status)
- Threat actors frequently mimic or subvert legitimate products and services for malicious purposes
- Unit 42 has no evidence of any compromise or vulnerability within these products or services related to this threat
